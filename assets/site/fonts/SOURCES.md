# Locally hosted fonts

OFL-1.1 variable fonts distributed through Fontsource, version 5.3.0:

- `@fontsource-variable/dm-sans`: DM Sans, Latin, normal, variable weight
- `@fontsource-variable/lora`: Lora, Latin, normal, variable weight
- `@fontsource-variable/cormorant-garamond`: Cormorant Garamond, Latin, normal, variable weight
- `@fontsource-variable/syne`: Syne, Latin, normal, variable weight

Downloaded from the canonical npm registry over verified TLS. Package archive
SHA-512 integrity was checked against registry metadata before extracting only
the Latin WOFF2 and the accompanying licence. Each font's complete OFL notice is
included in its corresponding `*-LICENSE.txt`. There are no runtime Google Fonts
requests. A page loads only the families it uses; unused files in the shared
asset directory are not automatically fetched. No font or artwork was generated.
